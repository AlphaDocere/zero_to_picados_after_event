## API Reference

### Endpoints
```
POST /api/agent-response
├─ Input: sessionId, agentId, initialMood, opinion, city
└─ Output: response, agentName, agentId, tone

POST /api/agent-memory/save
├─ Input: sessionId, agentId, responseText, outputType
└─ Output: { success, entryId }

GET /api/agent-memory/pending
├─ Query: agentId (optional), limit, status
└─ Output: Array of pending outputs

POST /api/save-session
├─ Input: userId, initialMood, finalMood, city, agent, opinion, checkInData
└─ Output: { sessionId, success }
```

## Component Architecture

### Check-in Flow
```
CheckInForm
  ├─ Step 1-4: Initial check-in
  ├─ Step 5: AgentSelector
  │   └─ Uses: getAllAgents() from agents.config
  ├─ Step 6: ResponseCard
  │   ├─ Calls: getAgentResponse()
  │   ├─ Shows: Personalized agent response
  │   └─ Saves: To agent memory (Firebase)
  ├─ Step 7: AgentFollowUp
  │   ├─ Uses: getAgent() for dynamic questions
  │   └─ Saves: User's reflection
  ├─ Step 8-9: Final summary
  └─ End: Session saved to Firebase
```

## Data Structures

### CheckInSession (Firebase)
```typescript
{
  userId: string
  initialMood: number          // 0-100
  finalMood: number            // 0-100
  city: string
  selectedAgent: string        // 'amplifier' | 'documentarian' | 'visionary'
  opinion: string              // User's reflection
  checkInData: {
    emotions: string[]
    thoughts: string
    physicalState: string
    environment: string
  }
  createdAt: timestamp
  updatedAt: timestamp
}
```

### AgentMemory (Firebase)
```typescript
// Path: /agents/{agentId}/outputs/{sessionId}
{
  sessionId: string
  responseText: string
  outputType: string           // 'preview' | 'discord' | 'notion' | 'webhook'
  status: string               // 'pending' | 'queued' | 'sent' | 'failed'
  metadata?: {
    targetService: string
    retryCount: number
    errorMessage?: string
  }
  createdAt: timestamp
  processedAt?: timestamp
}
```

## Agent Information

### Nova (Amplifier)
- **Role:** Amplifies voices globally
- **Tone:** Energetic, community-focused
- **Output Type:** Discord integration ready
- **MCP Target:** Discord webhook

### Atlas (Documentarian)
- **Role:** Archives insights
- **Tone:** Reflective, analytical
- **Output Type:** Notion integration ready
- **MCP Target:** Notion database

### Phoenix (Visionary)
- **Role:** Reveals potential
- **Tone:** Inspirational, forward-looking
- **Output Type:** Custom webhook ready
- **MCP Target:** Custom service/webhook
