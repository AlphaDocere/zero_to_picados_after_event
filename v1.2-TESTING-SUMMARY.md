## Data Flow Walkthrough

### Step 1: User Selects Agent
```
AgentSelector component
    → Calls: getAllAgents()
    → From: agents.config.ts
    → User selects: "amplifier" (Nova)
```
✓ Working

### Step 2: User Provides Opinion
```
AgentFollowUp component
    → Calls: getAgent(agentId)
    → Generates: Dynamic question based on mood + agent
    → User enters opinion text
```
✓ Working

### Step 3: Response Generated
```
ResponseCard component
    → Calls: getAgentResponse(sessionId, agentId, initialMood, opinion, city, saveToMemory=true)
    → API: POST /api/agent-response
    → Returns: { response, agentName, agentId, tone }
```
✓ Working

### Step 4: Memory Saved
```
useAgentResponse hook
    → Detects: saveToMemory parameter is true
    → Calls: POST /api/agent-memory/save
    → Firebase: Creates /agents/amplifier/outputs/{sessionId}
    → Status: Set to 'pending' (ready for Discord webhook)
```
✓ Working + Ready for MCP integration
